# Product Showcase

A responsive product showcase built with **React.js, Vite, and Tailwind CSS**. This project focuses on interactive product displays and practicing React's `useState` hook.
 
## Live Demo

[View Live Website](YOUR_NETLIFY_URL)
 
## Features

- Product listing with reusable React components
- Product categories and filtering
- Interactive UI using React state
- Responsive layout
- Clean and maintainable component structure

## Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/tariqhussainofficial03-div/products-using-usestate-hook.git
```

Navigate to the project directory:

```bash
cd products-using-usestate-hook
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

```bash
npm run build
```
